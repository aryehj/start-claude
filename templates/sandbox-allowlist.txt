# sandbox-allowlist.txt — default-deny egress allowlist for Claude Code's
# bubblewrap sandbox (sandbox.network.allowedDomains in settings.local.json).
#
# start-claude.sh reads this file and expands each bare domain 'd' to both
# 'd' (exact match) and '*.d' (all subdomains, any depth) when building the
# allowedDomains array. Edit this file here in the template, then run:
#   start-claude.sh --reseed-sandbox-allowlist
# to apply the update to a project's settings.local.json.
#
# Philosophy (mirrors start-agent.sh allowlist):
#   - Read-only hosts only.
#   - Write-capable hosts (github.com, container registries, huggingface.co,
#     data upload repos) are intentionally omitted.
#   - HTTPS git push to github.com is blocked under default config; add
#     github.com to your project's settings.local.json to re-enable.
#   - Comments start with '#'. Blank lines are ignored.
