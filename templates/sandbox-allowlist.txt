# sandbox-allowlist.txt — default-deny egress allowlist, shared by both
# launchers. One bare domain per line; a domain 'd' covers 'd' and every
# subdomain of 'd'. Comments start with '#'. Blank lines are ignored.
#
# start-agent.sh seeds a copy to $SANDBOX/.sandbox_config/allowlist.txt on
# first run; tinyproxy suffix-matches it. Edit that copy on the macOS host and
# run `start-agent.sh --reload-allowlist`. `start-agent.sh --reseed-allowlist`
# resets the copy to this template.
#
# start-claude.sh expands each 'd' to 'd' and '*.d' in the project's
# .claude/settings.local.json (sandbox.network.allowedDomains).
# `start-claude.sh --reseed-sandbox-allowlist` resets that list to this
# template.
#
# Philosophy:
#   - Read-only hosts only.
#   - Write-capable hosts (github.com, container registries, huggingface.co,
#     data upload repos) are intentionally omitted, so HTTPS git push to
#     github.com is blocked by default. Add the write host to your local copy
#     (allowlist.txt or settings.local.json) to re-enable it.
